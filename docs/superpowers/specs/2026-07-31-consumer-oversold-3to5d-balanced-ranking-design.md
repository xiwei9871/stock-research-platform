# 消费超跌修复：3—5日均衡排名 V2 设计

## 1. 背景

2026-07-29 冻结的统一 Top30 在 2026-07-30 的样本外表现显示：

- 收盘上涨 18/30，平均收益 +1.092%，中位数 +0.653%；
- 30/30 盘中一度上涨，说明候选池覆盖到修复行情；
- 排名 1—10、11—20、21—30 的上涨比例分别为 40%、60%、80%；
- 排名 21—30 的平均收益显著高于 1—10；
- 舍得酒业排名29、江淮汽车排名33但次日涨停；赛力斯排名1且次日收盘上涨5.948%。
- 北汽蓝谷属于整车审计范围且证据完整，但因 `oversold_score=56.98` 低于硬门槛60而被排除；其2026-07-27至30日累计上涨21.38%，其中7月29日涨停。

因此，现有模型对“是否存在中期修复逻辑”有一定识别力，但不能把当前总分解释为未来单日或未来3—5日强弱顺序。V2需要提高未来3—5日的上涨覆盖率与修复强度，同时保留基本面约束，不针对任何个股保护或反推名次。

## 2. 目标与非目标

### 2.1 目标

V2在基本面合格、风险可控且仍有修复空间的消费候选中，生成一张未来3—5个交易日的均衡修复榜单。

“均衡修复”同时包括：

1. 上涨覆盖率；
2. 平均与中位收益；
3. 涨幅达到3%、5%、7%的强修复比例；
4. 修复收益在3—5日内的留存；
5. 可接受的路径回撤。

### 2.2 非目标

- 不优化次日涨停命中率；
- 不保证北汽蓝谷、赛力斯、舍得酒业、江淮汽车进入Top20或获得特定名次；
- 不使用2026-07-28之后的数据生成2026-07-27排名；
- 不根据单个验证窗口无限搜索权重；
- 不允许人工直接加减分或调整最终名次；
- 不降低基本面、审计、债务、质押与永久减值风险标准。

## 3. 双门槛、单榜单

### 3.1 第一门槛：修复资格

第一门槛沿用并强化现有基本面与剩余修复空间要求：

- 属于经审计的整车企业或直接面向消费者的品牌；
- 满足6—12个月超跌、最大回撤或相对行业落后要求；
- 财务、估值、资产负债表与风险证据完整；
- 不存在审计、重大债务、质押或永久减值硬风险；
- 经营或估值修复尚未完成；
- 当前价格与近1—2年价格、长期均线及合理估值之间仍有可解释空间；
- 继续执行绝对价格条件：6个月收益不高于-20%或12个月最大回撤不高于-30%，且6个月相对行业收益不高于-10%；
- 基础情景上行空间不低于25%；
- `composite_score` 不低于30/100，作为基本面、估值、资产负债表、催化与超跌程度的综合质量底线；
- 未通过第一门槛的股票不能依靠技术面、股性或市值进入榜单。

现有 `oversold_score >= 60` 不再作为独立硬门槛。`oversold_score` 由回撤、6个月收益、相对行业收益、估值低位和长期均线偏差的截面分位合成，与上述绝对价格门槛存在重复，并会因截面和估值分位把满足绝对超跌条件的股票卡在任意切线上。V2保留该分数作为 `composite_score` 和修复潜力排名的输入，但不再单独决定资格。

北汽蓝谷不享有例外。它和所有股票一样，必须通过绝对价格条件、`composite_score >= 30`、证据完整、硬风险、资产负债表覆盖、修复未完成及第二道启动门槛，再由统一公式决定实际名次。

### 3.2 第二门槛：3—5日启动资格

第二门槛不再只是数据覆盖门槛，而是可执行的启动资格：

- 启动因子覆盖完整；
- 技术启动状态原始分不低于35/100；
- 近20日平均成交额和成交容量继续满足最低流动性要求；
- 不处于“加速下跌且尚未出现止跌信号”的状态；
- 不处于“短期涨幅已大、低点反弹充分且剩余修复空间不足”的过度延伸状态；
- 任一关键字段缺失不得按零值或最佳值处理。

门槛不得因合格股票数量不足而自动放宽。若通过两道门槛的股票不足30只，系统发布实际数量并明确标记覆盖不足。

### 3.3 单榜单

通过两道门槛后只产生一套确定性排名：

```text
final_rank_score_v2 = repair_rank_percentile * 55%
                    + activation_rank_percentile * 45%
```

首版权重固定为55/45。后续仅允许在多个冻结日期的走样本验证中，从以下有限组合选择：

- 60/40；
- 55/45；
- 50/50。

不做连续权重搜索。排序依次使用：

1. `final_rank_score_v2`降序；
2. `activation_rank_percentile`降序；
3. `repair_rank_percentile`降序；
4. `asset_id`升序。

系统输出正式Top20、候补21—40和完整合格池。Top30用于评价和诊断，不改变正式Top20的发布契约。

## 4. 3—5日启动分

```text
activation_score = technical_readiness_score * 30%
                 + continuation_character_score * 25%
                 + residual_price_space_score * 20%
                 + capital_efficiency_score * 15%
                 + catalyst_timing_score * 10%
```

五个组件只能在通过第一门槛且启动覆盖完整的统一截面内转成0—100分位；不合格或缺失股票不能污染分位。

### 4.1 技术启动状态：30%

技术启动状态使用分析日及之前的日线，判断股票是否由超跌转向止跌、企稳或早期转强：

- 5日、10日和20日绝对收益；
- 5日、10日相对所属消费子行业收益；
- 最近5日相对强弱相对于此前5日的改善；
- MA5斜率、MA10斜率、收盘价与MA5/MA10/MA20的关系；
- 当前收盘价在近20日区间的位置；
- 5日/20日成交额比、换手率变化与量价配合；
- 5日相对20日波动收敛，以及收敛后的向上扩张；
- 连续创新低、收盘持续低于短均线且相对行业继续恶化的“下落刀”扣分。

首版技术启动原始分按以下固定结构计算：

```text
technical_readiness_score = trend_turn_score * 30%
                          + relative_strength_improvement_score * 25%
                          + volume_turnover_confirmation_score * 20%
                          + moving_average_location_score * 15%
                          + volatility_transition_score * 10%
```

各子分先在第一门槛合格且字段完整的截面内转换成0—100分位。若同时满足“收盘低于MA5和MA10、MA5斜率为负、近5日相对行业收益位于后20%、最近3个交易日内创20日新低”，判定为加速下跌，不能通过第二门槛。

单日上涨或涨停不自动扣分。只有同时满足“近10日收益位于合格截面前10%、从60日低点反弹不低于30%、剩余价格空间分低于25/100”时，才判定过度延伸并退出第二门槛。

### 4.2 历史股性与延续性：25%

历史窗口继续限定在分析日之前最近两年，并严格使用分析日当时适用的板块与ST涨停制度。组件包括：

- 涨停、单日上涨不低于7%和5%的次数；
- 上涨尾部波动和上下行不对称性；
- 大阳线后1日、3日、5日继续取得正收益的频率；
- 大阳线后3日、5日累计收益中位数；
- 最大连续强势天数和强势留存率。

原始涨停次数只作为一个输入，延续率和后续累计收益的权重高于单纯次数，避免只奖励历史题材活跃。

首版内部结构固定为：强势次数20%、上涨尾部与上下行不对称15%、大涨后1/3/5日正收益率35%、大涨后3/5日累计收益20%、连续强势与留存10%。

### 4.3 剩余价格空间：20%

该组件只回答“启动后还有多少可修复空间”，包括：

- 距近1年、2年最高价的跌幅；
- 近1年、2年价格区间位置；
- 距MA120、MA250的偏差；
- 从近60日、120日低点已反弹幅度；
- 近6个月相对行业收益差；
- 当前估值距历史或行业合理水平的剩余空间。

历史相对价格指标继续使用后复权收盘价。

首版对上述十个剩余空间指标等权合成；方向统一为“剩余空间越大，得分越高”。任一指标缺失时该组件覆盖失败，不做缺项再归一化。

### 4.4 市值与资金推动效率：15%

市值组件由“越小越高分”改为合理甜蜜区间：

- 使用实际流通市值，缺失时回退实际总市值并明确标注；
- 对数市值极小端不再获得满分；
- 流动性不足的小市值股票受扣分；
- 市值很大且成交额/流通市值偏低的股票受推动效率扣分；
- 中等市值、成交活跃且资金容量匹配的股票得分较高；
- 甜蜜区间使用截面分位表达，不绑定固定人民币市值，避免跨市场阶段失真。

首版甜蜜区间为合格截面的流通市值15%—65%分位。区间内基础得分为95；低于15%分位时线性下降至截面最小端的35分，高于65%分位时线性下降至截面最大端的35分。基础得分再与成交额/流通市值、近20日平均成交额和换手率适配分等权合成。该规则不使用硬跳变，也不允许截面最小市值自动获得最高分。

### 4.5 催化时间适配：10%

催化必须可验证，并按与未来数周的相关性评分：

- 已知产品周期、旺季、渠道、政策或业绩窗口；
- 证据发布日期不得晚于分析日；
- 只有长期模糊叙事而无时间窗口时不得获得高分；
- 催化只改变合格股票内部排序，不能覆盖基本面或风险门槛。

催化时间适配沿用现有可验证性评分，并增加时间窗口分：未来20个交易日内存在明确窗口为100分，21—60个交易日为60分，只有方向性叙事而无时间窗口为20分，无可验证催化为0分；最终由可验证性和时间窗口各占50%。

## 5. 五分钟线的使用边界

首版V2不把五分钟线直接写入核心排名，原因是历史覆盖一致性和过拟合风险。五分钟线用于封存后的诊断标签：

- 首次达到日内最高价时间；
- 盘中最大涨幅；
- 收盘较高点回撤；
- 高于前收的5分钟bar比例；
- 上午与下午修复留存；
- 涨停时间与是否保持至收盘。

只有在多个冻结日期具有一致完整覆盖、且独立消融测试证明增加稳定样本外价值后，五分钟因子才可进入后续版本。

## 6. 评价框架

每个历史分析日先封存候选和排名，再读取未来行情。主要观察未来3日和5日：

### 6.1 修复比例

- 收盘累计收益大于0的数量和比例；
- 相对所属消费子行业取得正超额收益的比例；
- 第3日和第5日仍保持正收益的比例。

### 6.2 修复强度

- 平均累计收益；
- 中位累计收益；
- 上涨股票平均累计收益；
- 累计涨幅不低于3%、5%、7%的数量和比例；
- 期间达到3%、5%、7%但期末未留存的数量和比例。

### 6.3 风险与留存

- 路径最大回撤；
- 期间最高收益到期末收益的回撤；
- 第3日与第5日收益留存；
- 极端亏损比例。

### 6.4 均衡评价

跨多个冻结窗口选择有限权重组合时采用：

```text
balanced_evaluation = breadth_quality * 40%
                    + repair_strength * 40%
                    + risk_and_retention * 20%

overall_evaluation = evaluation_3d * 30%
                   + evaluation_5d * 70%
```

次日收益、次日涨停和五分钟结构只作为诊断，不进入主调参目标。

## 7. 2026-07-27 首个冻结测试

### 7.1 冻结规则

- 分析日固定为2026-07-27；
- 排名只能使用2026-07-27收盘及之前可获得的数据；
- 2026-07-28、29、30的日线和五分钟线只能用于评价；
- 财务、公告、风险证据、行业成员关系不得晚于2026-07-27；
- 同时生成V1旧排名和V2新排名，不覆盖历史封存产物。

### 7.2 验收范围

- Top20为正式榜单评价；
- 同时评价Top30整体表现；
- 分别统计排名1—10、11—20、21—30；
- 比较V1与V2的成员变化、名次变化及逐项因子分解；
- 评价2026-07-28、29、30每日收益、截至各日累计收益和三日路径风险；
- 输出三日内盘中修复与收盘留存诊断。

### 7.3 首个窗口的解释边界

7月27日冻结、28—30日验证只用于验证实现、解释因子行为并发现明显缺陷。不得仅凭该窗口确定最终权重或门槛。权重调整至少需要20个不同冻结日期，并覆盖上涨、下跌和震荡市场环境。

## 8. 排名单调性与基准

每个评价窗口必须比较：

- Top1—10、11—20、21—30的上涨比例、平均和中位收益；
- 最终排名与3日、5日收益排名的Spearman相关性；
- Top20相对全部双门槛合格候选的等权表现；
- V2相对V1的增量表现；
- 成员命中不能替代组合统计。

单个窗口不要求三个分段严格单调，但若多个窗口中Top1—10长期不优于11—20或21—30，应判定排序缺乏有效性。

## 9. 输出产物

V2运行至少生成：

1. V2统一Top20；
2. V2候补21—40；
3. V2完整双门槛合格池；
4. V1/V2排名对照；
5. 修复潜力、五个启动组件、启动分和最终分的逐项分解；
6. 第二门槛排除原因；
7. 3日、5日前瞻评价明细与汇总；
8. Top1—10、11—20、21—30分段报告；
9. 五分钟盘中诊断报告；
10. 数据覆盖、日期上限和未来数据隔离审计。

## 10. 测试要求

### 10.1 单元测试

- 第一门槛失败的股票不能由启动分救回；
- `oversold_score` 低于60但绝对超跌条件、基础上行空间和 `composite_score >= 30` 均通过时，不得仅因该分数被排除；
- `composite_score` 低于30时，即使跌幅、股性和启动分很高也不能通过第一门槛；
- 技术启动原始分低于35时不能进入最终排名；
- 缺失关键启动字段不得按零分、平均分或满分处理；
- 单日大涨但剩余空间充足时不被机械剔除；
- 单日未涨但仍在加速下跌时不能获得高启动分；
- 历史延续率高于单纯涨停次数对股性分贡献更大；
- 市值甜蜜区间优于极小端和极大端；
- 最终排名不存在个股白名单、人工调整或名称分支；
- 北汽蓝谷、赛力斯、舍得酒业和江淮汽车均不得触发任何按代码或名称编写的资格与排名逻辑；
- 相同输入必须产生相同排名。

### 10.2 时点与集成测试

- 2026-07-27排名查询不得读取2026-07-28之后数据；
- 评价器必须读取冻结产物，不得重新计算历史成员；
- V1与V2产物并存且不可相互覆盖；
- Top20、Top30和三个排名分段统计加总一致；
- 日线覆盖不完整时不得发布完整评价；
- 五分钟数据不完整时核心评价仍可运行，但盘中诊断必须明确降级。

## 11. 后续调整原则

首版按本设计固定运行。后续调整必须满足：

- 使用多个冻结日期的样本外评价；
- 先提出假设，再验证因子，不根据个股结果倒推；
- 每次只调整一个明确问题；
- 保留V1、V2和后续版本的可复现产物；
- 任何权重变化都要报告对上涨比例、收益强度、回撤和排名单调性的影响。
