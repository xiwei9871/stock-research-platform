# Dragon / 龙虎榜 / 主线事件策略研究总纲 v1

## 1. 策略定位

本研究线不再定位为“龙虎榜追涨策略”，而定位为：

> 主线环境下的短线事件风险收益诊断系统。

核心问题不是“龙虎榜能不能带来高胜率”，而是：

```text
在什么市场环境下，
什么主线板块中，
什么事件结构的股票，
配合什么龙虎榜资金行为，
能够提高 1/3/5 日收益，或者降低 A杀、假二波、一日游风险。
```

当前系统应优先回答：

- 现在适不适合做短线人气股；
- 哪些方向是市场主线；
- 哪些人气股事件结构值得观察；
- 哪些龙虎榜行为更像资金撤退或高位分歧；
- 哪些票应该被风险过滤排除。

最终产出暂定为 `daily_dragon_watchlist`，即短线事件观察池，而不是实盘买入信号。

## 2. 不做什么

短期明确暂停：

1. 不做 Dragon 买入排序和正式组合回测。
2. 不把 LHB 接入买入打分。
3. 不把行业热度作为正向 alpha 加权。
4. 不为了样本数量无限扩案例库。
5. 不做实盘交易、不接自动下单、不输出交易指令。
6. 不用 future return 参与任何当日信号、分数或过滤规则。

这些模块可以继续保留为诊断能力，但不能越界进入策略打分。

## 3. 五层研究框架

### 第一层：市场环境判断

回答：

```text
现在适不适合做短线人气股？
```

候选指标：

- 市场总成交额；
- 涨停数量；
- 跌停数量；
- 连板高度；
- 炸板率；
- 昨日涨停溢价；
- 高位股亏钱效应；
- 大盘趋势；
- 小票和题材活跃度。

建议状态：

- `mainline_market`：主线行情；
- `rotation_market`：轮动行情；
- `cooling_market`：退潮行情；
- `ice_repair`：冰点修复；
- `high_position_risk`：高位风险期。

这一层决定：能不能做。

### 第二层：主线板块判断

回答：

```text
资金现在聚焦在哪些方向？
```

候选指标：

- 板块成交额占全市场比例；
- 板块 3/5/10 日超额收益；
- 板块内涨停数量；
- 板块内上涨家数占比；
- Top20 / Top50 / Top100 候选密度；
- 龙头是否向中军、补涨扩散；
- 新闻、政策、产业催化。

主线模块的定位是：

- 主线识别；
- 市场解释；
- 风险暴露约束；
- 事件研究分组。

主线模块暂不承担个股正向 alpha 加权。

### 第三层：个股事件结构

回答：

```text
这只股票处于哪种短线结构？
```

重点事件：

- `continuous_limit_up`：连板；
- `break_then_reversal`：断板后反包；
- `second_wave`：二波启动；
- `failed_second_wave`：二波失败；
- `failed_reversal`：假反包；
- `weak_to_strong`：弱转强；
- `high_open_low_close_failure`：高开低走或冲高回落失败；
- `one_day_pump`：一日游；
- `a_kill_failure`：A杀；
- `dragon_pullback`：龙回头。

研究重点不放在抢一板，而放在：

```text
已被市场确认的人气股，
在断板、分歧、回踩后，
是否还能二次加速。
```

这一层决定：股票是否进入观察区。

### 第四层：龙虎榜资金行为

回答：

```text
龙虎榜是在确认承接，还是暴露撤退？
```

当前结论是：LHB 更像风险诊断层，而不是稳定买点确认层。

候选字段：

- 是否上榜；
- 上榜原因；
- 净买额；
- 净买额占比；
- 机构净买；
- 机构卖出；
- 重复上榜次数；
- Top 席位集中度；
- 事件前、事件日、事件后上榜；
- `lhb_one_day_pump_risk`。

当前更有价值的风险字段：

- `lhb_negative_net_buy`；
- `lhb_institution_selling`；
- `lhb_high_pump_risk`；
- `lhb_repeat_attention`；
- `lhb_after_event_attention`；
- `lhb_risk_score`。

这一层决定：是否需要排除或降权风险。

### 第五层：安全性过滤

回答：

```text
这只票有没有不能碰的硬风险？
```

过滤项：

- ST / *ST；
- 退市风险；
- 重大负面公告；
- 严重财务风险；
- 极端高位监管风险；
- 流动性异常；
- 短期涨幅极端且无承接；
- 高位大额减持或解禁压力。

这一层决定：能不能进入最终观察池。

## 4. 三条研究线

### 方向 A：短线风险过滤系统

这是当前最成熟、最值得优先推进的方向。

目标不是选出上涨股票，而是排除高风险股票。

重点识别：

- A杀风险；
- 失败二波；
- 假反包；
- 高开低走；
- 一日游；
- 高位退潮；
- 资金撤退。

使用字段：

- `dragon_risk_score`；
- `overheat_avoid`；
- `crowded_late_entry`；
- LHB 负净买；
- 机构卖出；
- 高 pump risk；
- 事件后重复上榜；
- 高位冲高回落。

验证指标：

- 过滤后 A杀样本是否减少；
- 过滤后最大回撤是否下降；
- 过滤后失败二波比例是否下降；
- 过滤后 3/5 日亏损概率是否下降。

### 方向 B：主线确认 + 二次加速候选系统

这是“骑龙”方向，但只能在风险过滤稳定后推进。

目标是找：

```text
主线板块中已经走出来的人气股，
在分歧后仍然具备二次加速可能。
```

重点事件：

- 断板后反包；
- 二波突破；
- 弱转强；
- 龙回头；
- 强分歧后继续走强。

候选条件：

- 市场环境不是退潮；
- 板块仍是主线；
- 个股前期有人气确认；
- 断板不 A 杀；
- 分歧后有承接；
- LHB 没有明显撤退信号；
- 技术指标不过热或已修复。

验证指标：

- 未来 1/3/5 日收益；
- 未来 1/3/5 日最大回撤；
- 是否再涨停；
- 是否冲高回落；
- 是否二波失败；
- 是否 A杀。

### 方向 C：案例库 + 机制归纳

案例库用于规则归纳和机制校验，不用于证明策略收益。

当前重点补齐：

- `failed_reversal`；
- `high_open_low_close_failure`；
- `one_day_pump`；
- 2026 失败样本。

案例库应同时包含成功案例和失败反例，避免只看走出来的牛股导致幸存者偏差。

## 5. 研究阶段计划

### 第一阶段：统一研究目标

产出：

- 本总纲；
- 事件定义字典；
- 市场环境状态定义；
- 主线板块定义；
- LHB 风险字段定义；
- 安全过滤字段定义。

### 第二阶段：完善失败事件识别

优先修：

- `failed_reversal`；
- `high_open_low_close_failure`；
- `one_day_pump`；
- `failed_second_wave`；
- `a_kill_failure`。

产出：

- `failure_event_rule_v2`；
- `failure_event_audit`；
- 失败类型对比表。

### 第三阶段：LHB 风险层固化

把 LHB 固化成风险诊断字段：

- `lhb_negative_net_buy`；
- `lhb_institution_selling`；
- `lhb_high_pump_risk`；
- `lhb_repeat_attention`；
- `lhb_after_event_attention`；
- `lhb_risk_score`。

产出：

- `lhb_risk_feature_v2`；
- `lhb_risk_score_diagnostics`；
- LHB 风险字段有效性报告。

### 第四阶段：主线环境诊断重做

不做行业正向加权，而是回答：

- 当前是否存在主线；
- 主线是否扩散；
- 主线是否过热；
- 主线是否退潮。

产出：

- `market_emotion_regime`；
- `theme_mainline_regime`；
- `short_term_trading_regime`。

### 第五阶段：构建候选观察池

观察池不是买入池。

候选条件：

- 市场环境允许；
- 板块主线有效；
- 个股有事件结构；
- 风险标签不过高；
- 安全过滤通过。

输出：

```text
daily_dragon_watchlist
```

字段：

- 入选原因；
- 当前事件结构；
- 主线状态；
- LHB 风险；
- 技术状态；
- 安全过滤结果；
- 风险提示；
- 未来观察窗口。

### 第六阶段：模拟观察，不交易

每天生成观察池并跟踪：

- 次日表现；
- 3 日表现；
- 5 日表现；
- 最大回撤；
- 是否冲高回落；
- 是否涨停；
- 是否 A杀。

观察周期至少 1-3 个月。

### 第七阶段：事件回测

只有观察池表现稳定后，才进入事件回测。

回测形式应是事件回测，不是传统组合回测：

- 事件日后买入；
- 次日确认买入；
- 持有 1/3/5 日；
- 触发风险退出。

## 6. 进入回测的条件

必须同时满足：

1. 失败事件识别能稳定区分 `failed_second_wave`、`a_kill_failure`、`failed_reversal`、`one_day_pump`。
2. LHB 风险字段能稳定解释回撤或亏损概率。
3. 主线环境分组后，事件收益和回撤有清晰差异。
4. 观察池连续 1-3 个月表现出可解释优势。
5. 安全过滤能减少硬风险样本。
6. 所有信号字段严格不使用 future return。

## 7. 停止研究的条件

满足任一条件，应停止把它推进为交易策略，只保留为复盘工具：

1. 失败识别不能降低 A杀、失败二波或一日游暴露。
2. LHB 风险分无法稳定解释回撤。
3. 主线环境分组后仍没有收益或风险差异。
4. 观察池连续 1-3 个月无优势。
5. 规则只能在少数案例上解释，无法扩展到样本外。
6. 需要大量参数拟合才能得到好结果。
7. 研究结论依赖未来函数或人工事后判断。

## 8. 当前战略判断

当前研究方向定为：

> 短线右侧事件风险收益系统，而不是简单龙虎榜追涨系统。

核心假设是：

```text
在主线行情中，
人气股事件结构已经形成后，
龙虎榜资金行为和风险标签，
可以帮助区分“二次加速”和“高位失败”。
```

因此，下一步优先级是：

1. 完善失败事件识别；
2. 扩大高优先级 LHB 覆盖；
3. 固化 LHB 风险层；
4. 重做主线环境诊断；
5. 构建观察池；
6. 观察 1-3 个月；
7. 再考虑事件回测。

## 9. 边界检查

- 本总纲不新增策略代码。
- 本总纲不新增回测。
- 本总纲不接实盘。
- 本总纲不把 LHB 作为买点信号。
- 本总纲把行业模块限定为主线识别和风险暴露约束。
- 本总纲把案例库限定为规则归纳和机制校验。
