# M1 Research-Only Pilot: Theme Evidence to Competitive-Moat Dossiers

**As of:** 2026-10-19  
**Scope:** Read-only research pilot using existing production Theme Research records. This is not an investment recommendation or investment advice. No production data, review status, report publication, mapping, signal, admission, Top5, or quality-pool state was changed.

## Method and evidence standard

Read-only production Theme Research API `GET` responses and PostgreSQL session `service=theme_research_runtime` were used; each DB read ran in a transaction after `SET TRANSACTION READ ONLY`. No source PDFs/reports were downloaded or newly acquired. Source dates below are publication dates in the existing records, not verified collection/availability dates. Production currently contains 25 themes, 270 nodes, 268 sources, and 236 company mappings; source data is stale and lacks `available_at`/`collected_at`, so this dossier is not point-in-time-complete. The Theme Research source set contains only two broker-report records, both S2 / `needs_full_text`; neither is used as proof here. Evidence references are record IDs and the existing page/excerpt locators, with short paraphrases only.

Labels used:
- **Fact (recorded):** directly reflected by an accepted source/evidence item or current production status, within that record's stated scope.
- **Estimate / platform assessment:** a stored confidence, priority, score, or categorization; not an independently measured outcome.
- **Unknown / evidence gap:** the records do not establish the proposition. Unknown is not evidence of absence.

The existing `reviewed` state is a workflow status, not proof of a durable moat. The theme's `research_priority_score` and company research-priority scores are for research triage only; they are not investment attractiveness, valuation, or signal scores. This pilot adds no new score or evaluation entity.

## Gates, workflow, and safety

- **Overall M1:** research-only pilots show how existing `Source → Claim → Node → Company Mapping` records can carry product evidence, counterclaims, unknowns and locators. The required end-to-end reviewed-claim click-through and Theme/Stock bidirectional navigation were not tested. The two reviewed-theme examples lack customer validation, competitor comparisons and full financial realization evidence; robotics is deliberately downgraded. **M1 gate remains open / not passed.**
- **M3:** no portal, UI, API, permission, automated navigation test, strategy experiment surface or report publication was added or tested. The M3 end-user and test-account gate is **not assessed / not passed**. The existing pending AI-power report version `2026-08-03.1` remains pending review (markdown + manifest, no PDF); this pilot does not publish or approve it.
- **M4:** no refresh, expiry/revalidation trigger, feedback ledger, migration, or production process was implemented. The known lack of source `available_at`/`collected_at` and stale/revalidation policy remains a blocker to a point-in-time and durable review loop; **M4 gate not assessed / not passed**.
- Existing review flow is reused conceptually; no parallel portal or review system is proposed. No report version/status or mapping changed. No signal/admission, Top5, quality-pool, formal strategy, or production database change occurred.

**Conclusion:** evidence supports selected product relevance in the two reviewed themes, but not durable company moats. The only defensible humanoid-robotics conclusion is unknown. Further M1 work should first close source traceability/click-through and collect customer, competitor, segment economics, cash-flow, and counter-evidence records under the existing review flow.
