## 结构（本轮重构）

- 单图双子图：上=累计净申购折线（5 车道），下=每日净申购柱（红申购/绿赎回），共享一个 x 轴——不存在"下图不能交互"的第二图表。
- 垂直虚线贯穿：hover 任意子图在 shapelayer 画 paper 0→1 全高点线，位置精确吸附交易日。
- 整合数据框：自定义 tooltip 同时显示 日期 + 各可见车道累计值 + 当日净申购(随柱状图选择器) + 覆盖/剔除质量注；在图例开启混合/未披露/未知后同样并入。

## 功能核验（两浏览器均通过，0 console 错误）

- 整合框实测：`2026-09-18` → 个人累计 6623.1 / 机构累计 −4123.7 / 每日净申购·全部ETF −53.7 / 覆盖 1307/1308；剔除/缺失 1 行。
- 区间缩放天然共享 x 轴（单子图无同步逻辑）；区间按钮、自定义日期、双端 0 错误。
- 非交易日边界：输入 2026-01-24(六)~02-01(日) → 实际渲染 2026-01-26~01-30；反向输入 02-01~01-20 → 交换为 01-20~02-02（均为交易日），不虚构数据。
- 刻度自适应：全历史 `%Y`；一年 `%Y-%m`；≤45 天 `%Y-%m-%d`（月视图实测刻度 09-27/09-30/10-03…；周视图逐日 10-19…10-27）。日频原始数据无任何聚合。
- 分类口径切换 PIT ↔ latest-fixed，柱状图分类 全部ETF/机构主导/个人主导 独立切换，互不污染。
- 累计基准固定 2020-01-02，缩放不重置；"区间重新累计"为显式 checkbox。
- CSV 导出所选区间（daily+cum 十列）与 PNG 导出（双图）正常；图例点击开关混合/未披露/未知车道。
