# R1.1 方法审计与定向复验报告

基线：R1 commit `3cd01d33`。本轮只修方法问题，不扩展假设。结论：**四项修复中三项改变了具体数值，一项（回测）实质改变了 R1 的方向性表述；H1–H4 判定不变，但 H1 的"弱支持"进一步减弱。**

## P0-1 回测时间对齐 —— 确认存在重复滞后

R1 的 `backtest()` 缺陷（`analyze_r1.py` 旧版）：

| 步骤 | R1 实际行为 | 正确行为 |
|---|---|---|
| T 日信号 | z20≤−2 在 T 日数据上判定 | 同左 |
| 退出执行 | C 内已用 `sig[t-1]` 令 `posC[t]=0`（自带 T+1），随后 `np.roll` 又滞后一次 → **实际 T+2 生效** | 信号 → 单次 roll → T+1 |
| 再入场 | 用未 roll 的 `posB[t]` → T+1 | 同左 |
| 结果 | **退出 T+2、入场 T+1 不对称** | 统一 T+1 |

R1.1 修复：原始仓位信号单次 roll；成本在执行日（仓位变动日）扣除；输出 `BACKTEST_TRADE_LOG.csv` 逐笔流水（exec_date/signal_date/仓位/信号值）；断言 `pos[1:]==raw[:-1]`。

**结果对比**（见 `DIFF_R1_VS_R11_BACKTEST.csv`）：R1 报告 C 回撤 −22.3%、年化 +1.9%；修正后 **C 回撤 −34.4%、年化 +0.6%**，差于 B（−24.4%）。R1 中 C 的"优势"部分来自错位时序，**修正后 ETF 流出条件未能改善风险管理**——R1 的"边际改善"表述应下调为"未见改善"。

## 新框架下的重要发现（如实报告）

- **资金对过去收益呈逆势响应**：corr(idx_ret20, 未来20日F20) = **−0.19**（G2，n=1630）——跌→流入、涨→流出，与"逆周期/稳定器"假设方向一致；但 corr(F20, 未来收益) 仅 20–60 日弱正（+0.12~0.14）、120 日转负、且训练/样本外符号翻转 → **资金跟随价格的可证性 > 资金领先价格的可证性**。
- **924 案例（只凭事前信息）**：2024-09-23 政策公布前一日 G2 F20=**+8.6%**、指数 20 日 −3.0%——持续性流入在数据内可观察，无需事后政策解释；但同一形态在 2024-06-21~07-08 也曾出现（假阳性早期簇）。**单个案例不能外推为规则**。
- 2026-07 回补确认：7 月下旬 G2 F20=+34.7%（AUM 缩水后的强度口径），归因仍不可到具体主体。
