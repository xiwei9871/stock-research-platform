# ETF-FLOW-R1 研究计划（预注册版）

**本文件在任何结果计算之前写成。阈值、窗口、分组规则在此固定，后续不得根据结果择优调整。**
基线数据：POC-02.1 管线产物（`etf_daily_flows_v2.csv` 等），分支 `poc/etf-flow-03` @ `2805e40c`。

## 假设

- H1：头部宽基/机构主导 ETF 连续净赎回领先更大未来回撤与大跌概率（尾部，非均值）。
- H2：持续赎回后转为净流入/赎回减速，对应更好的未来收益-回撤比（底部识别）。
- H3：科技 ETF（半导体/AI算力/机器人/软件信息/科创）净赎回领先 2026-08 板块下跌；重点窗 2026-06~08。
- H4：价格涨+资金赎回 / 价格跌+资金申购 的背离与未来风险存在稳定联系。

## 预注册阈值与定义（一律 T-1 及更早数据形成基线）

| 项 | 定义（固定） |
|---|---|
| 强度 F1 | `flow_t / AUM_{t-1}`，组合=Σ流量/Σ前日规模 |
| 持续流 F2 | 5/10/20 日强度累计和 |
| 异常度 F3 | `z20_t = (Σ20d强度 − mean60(T-1)) / std60(T-1)`；稳健版 `MAD20`；事件= z20 ≤ −2（流出）或 ≥ +2（流入），相邻事件 20 日内去重取首个 |
| 加速度 F4 | `acc = mean5强度 − mean20强度`（近5强于近20=流入恢复；反之流出加速）|
| 背离 F5 | A: 20日指数涨幅 > +2% 且 z20 < −1；B: 20日指数涨幅 < −2% 且 z20 > +1 |
| 尾部 | 未来 5/10/20/40/60 日内最大回撤；大跌事件 = 窗口内回撤 ≤ −5% / ≤ −10% |
| 执行时点 | T 日数据收盘后可见 → 信号 T 日确认，T+1 执行 |
| 对照组 | 按事发前 20 日指数收益、60 日波动率、回撤水平分桶匹配的非事件日 |
| 样本外 | 训练 2020-01~2023-12；OOS 2024-01~2026-10，单独报告 |
| 基线 B | 价格风控：20 日动量 <0 或收盘 <200 日均线 → 空仓，反之满仓（两条件并集，固定）|
| 实验 C | B 基础上叠加：z20 ≤ −2 → 强制空仓；z5 ≥ 0 且非 z20 ≤ −2 → 允许恢复持仓 |
| 成本 | 单边 0.05%，换手计入 |

## 分组（互斥主统计，重叠只作标注）

G1 全部A股股票ETF；G2 沪深300头部（510300/510310/510330/159919 + 510050）；G3 其他宽基（上证50以外中证500/1000/创业板/科创50/A500/中证全指等名称判定）；G4 科技整体=G5∪G6∪G7∪G8∪科创其他；G5 半导体（名称含半导体/芯片/集成电路）；G6 AI/算力（人工智能/AI/算力/云计算/大数据/通信/5G）；G7 机器人（机器人/智能制造）；G8 软件信息技术（软件/信息技术/计算机/信创/数字经济）。其余股票ETF归入 G1 但不入 G2-G8。

## 统计注意

- 前瞻窗口重叠 → 用 moving-block bootstrap (block=40d) 估计置信区间；报告事件样本量与失败案例。
- 多重检验：组内检验按 Benjamini-Hochberg FDR q=0.1 标注存活与否。
- 510310 等异常：Gate 0 先判定；含/剔两口径敏感性，结论不得由异常样本决定。
- 机构/个人仅为分类切片，不表述为实际交易主体。
