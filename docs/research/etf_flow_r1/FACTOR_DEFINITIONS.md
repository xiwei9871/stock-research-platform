# FACTOR_DEFINITIONS — R1 因子与阈值（预注册，分析前固定）

实现见 `analyze_r1.py:factors()`。所有基线仅使用 T−1 及以前数据。

## 数据口径

- 日净申购 `flow_yi = (shares_t − shares_{t−1}) × NAV_t / 1e8`（亿元；公司行为日用 `flow_use` 剔除）。
- 组流量 = 组内基金当日净申购合计；组 AUM = 组内基金 `shares×NAV` 合计。
- 组收益：板块代理 = 组内基金市值加权 `NAV` 收益；G2 用沪深300指数、G3/G1_all 用中证全指。

## F1 净申购强度
`i1_t = flow_yi_t / AUM_{t−1}`（组口径：组流量合计 / 组前日净资产合计）

## F2 持续净流强度
`iW_t = Σ_{k=0..W−1} i1_{t−k}`，W ∈ {5, 10, 20}

## F3 异常资金流（z-score，60 日基线，仅用 T−1 前）
`mu_t = mean(i20_{t−60..t−1})`，`sd_t = std(i20_{t−60..t−1})`
`z20_t = (i20_t − mu_t) / sd_t`
稳健版：`z20_mad = (i20_t − median) / (1.4826 × MAD)`
- 异常流出事件：`z20 ≤ −2`（宽松档 −1；从严档 −2.5 另报）
- 事件去重：相邻事件间隔 ≥20 交易日（32 个自然日）

## F4 流入/流出加速度
`acc_t = mean(i1_{t−4..t}) − mean(i1_{t−19..t})`（近 5 日均值 − 近 20 日均值）

## F5 价格/资金背离
- A 类（指数上涨+资金流出）：`idx_ret20 > +2%` 且 `z20 < −1`
- B 类（指数下跌+资金流入）：`idx_ret20 < −2%` 且 `z20 > +1`
- 同样按 ≥20 交易日间隔去重

## H2 反转事件
过去 10 日内 `min(z20) ≤ −1` 且当日 `i5 ≥ 0` 的首次出现。

## 前向指标
对每个事件日 T 与窗口 w ∈ {5,10,20,40,60}：
- `fwd_ret_w = Σ ret_idx_{T+1..T+w}`
- `fwd_mdd_w = min(px_{T+1..T+w}) / px_T − 1`
其中 `ret_idx` 为组对应指数收益，`px` 为其累计净值。

## 对照组
同日 `idx_ret20` ±3pp 且 `vol60` 在事件日 [0.7×, 1.3×] 内、距任一事件 ±20/40 交易日之外的非事件日，取该窗口 `fwd_mdd` 均值。

## 置信区间
移动块自举（block=40），事件数 <40 时退化为独立有放回自举；报告 5–95 分位。

## 交易执行约定
信号最早于 T 日收盘后确认，策略持仓自 T+1 生效；双边交易成本 0.05%/边。

## 样本外划分
训练段 2020-01 至 2023-12；样本外 2024-01 至 2026-10，单独报告相关性。
