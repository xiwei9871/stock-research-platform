# ETF 融合失效根因（已定位，非 UNRESOLVED）

**结论：学习型符号错误 + 极端分布外输入 + 一个全缺失死特征。三层叠加。**

## 1. 学到的符号与现实相反（统计根因）
训练期(2020-23)内，G2沪深300头部ETF的深幅持续净赎回主要对应机构轮动/上涨期（例：A01深45%→fwd+15.9%），logistic 学到：
- `g1_depth` 权重 **−0.565**（深度越大→风险越低）
- `g2_vel20` 流出速度为负时贡献为负（赎回加速→降压）

## 2. 2026年7月输入极端出界（数据根因）
- `g2_depth` replay 均值 0.81–1.06（训练 max 0.455）→ z≈+6.1，负权重×极端z = 贡献 **−1.62**
- `g2_vel20` 7/1 值 −3.89%/日 → z=−9.63，贡献 **−2.14**
- 仅两项合计 −3.76 logits ≈ 把 0.51 概率压到 0.004

## 3. 死特征（代码根因）
- `g1_breadth` replay **100% NaN**（G1聚合口径无该列，R3已知），`fillna(0)` 使其恒零——无效占位但无害。
- `fillna(0)` 语义混杂：NO_ACTIVE_CYCLE(≈48%训练期)与DATA_MISSING同编码为0，不应再用于正式特征。

## 4. 机制总结
B(7/1)=0.507 → C(7/1)=0.004：ETF特征把概率压掉了 0.50。这不是"ETF资金没信息"，而是**信息被历史符号反转+线性外推到2倍量程**。消融显示仅 g1_depth 单特征(B3)在valid段不降分（0.513 vs B0 0.498）——深度本身有弱信息，整组喂入则引入相关噪声+符号漂移。
