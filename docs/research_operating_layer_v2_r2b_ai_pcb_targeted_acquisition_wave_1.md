# AI PCB Targeted Evidence Acquisition Wave 1

## Scope

Wave 1 executed the frozen exact-list Gate for `PCB-ER-A01`, `A02`, `A03`, `A04`, `B01`, and `B02`. All formal network attempts used the existing `direct_http` provider with `proxy_mode=direct`, provider-local `trust_env=False`, TLS verification and fail-closed SSRF validation. No Evidence Assessment, claim update, cognition update, bottleneck/value judgment, company mapping, Stage A2 or Stage B was started.

## Execution

The internal order was preserved: A01/A04/B01, then A02/A03, then B02. Official standards and technical sources were selected for channel definitions, insertion-loss measurement, dielectric-property methods and copper-roughness variables. Search snippets and discovery metadata were not stored as evidence.

An initial engineering preflight exposed a candidate-identity contract mismatch before any network request or raw publication. Those failed global attempts remain immutable. The root cause was corrected by deriving provider candidate IDs from the provider URL/title identity contract; no security or scope policy was weakened.

## Result boundary

The final checkpoint contains 16 screened candidates and 16 formal attempts: 11 acquired PDFs, three fail-closed security blocks, one timeout and one HTTP 403. The acquired records resolve to seven unique raw hashes and six provisional acquisition-level evidence chains after exact duplicate and suspected common-origin grouping. Ten normalized representations succeeded; one encrypted PDF retained its immutable raw artifact with a separate normalization failure.

This checkpoint only establishes a candidate evidence collection suitable for later strict review. It does not assert ER sufficiency. A04 lacks the intended independent NIST measurement source, B01 lacks an acquired independent supplier/measurement chain and includes one encrypted normalization failure, and all acquired artifacts retain unknown publication dates pending later evidence review.
